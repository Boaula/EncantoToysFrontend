# Atalhos de Teclado - Encanto Toys PDV

## PDV (Ponto de Venda)

| Tecla | Ação |
|-------|------|
| **F2** | Focar no campo de busca de produtos |
| **F3** | Limpar o carrinho de compras |
| **F4** | Abrir tela de finalização de pagamento |
| **ESC** | Limpar o campo de busca |

## Navegação

- Use **Tab** para navegar entre campos
- Use **Enter** para selecionar produtos ou confirmar ações
- Use **Setas** para navegar em listas

## Dicas de Uso

- O campo de busca aceita: nome do produto, código de barras ou categoria
- Ao adicionar um produto que já está no carrinho, a quantidade é automaticamente incrementada
- O sistema valida o estoque disponível antes de adicionar produtos
- Produtos com estoque ≤ 10 unidades são destacados com badge de alerta
